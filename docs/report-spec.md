# CourtIQ report specification

## 1. Game Report

Purpose: permanent record of one fixture.

Pages:
1. Cover + final score
2. Quarter-by-quarter score
3. Team comparison
4. Player box scores
5. Shooting/rebounding/turnover breakdown
6. Key observations
7. Source/verification metadata

## 2. Opponent Scouting Report

Purpose: pre-game preparation.

Pages:
1. Opponent overview + record
2. Recent form
3. Offensive profile
4. Defensive profile
5. Key players
6. Statistical tendencies
7. Previous head-to-heads
8. Strengths and vulnerabilities
9. Recommended game plan

## 3. Team Season Report

Purpose: season-long review.

Include:
- Fixture record
- Scouted-game coverage
- Team averages
- Player averages
- Quarter trends
- Home/away splits
- Shooting trends
- Rebounding/turnover trends
- Best/worst performances

## 4. League/Opponent Database Report

Purpose: aggregate all verified games available to CourtIQ.

Include:
- Team comparison
- Opponent rankings
- Head-to-head history
- Recent-form trends
- Player leaderboards
- Data coverage indicators

## PDF principles

- Coach-readable first; raw data second.
- Never present an estimate as verified fact.
- Display sample size beside aggregated statistics.
- Include the report generation date.
- Include the number of verified games used for each historical insight.
- Keep reports printable on A4.
