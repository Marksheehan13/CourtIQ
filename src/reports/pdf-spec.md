# CourtIQ PDF Report Specification

## Opponent scouting report

### Cover
- Opponent
- Upcoming fixture
- Report generated date
- Verified-game sample size

### Executive summary
- Evidence-based scoring profile
- Recent form
- Key statistical trends
- Confidence/sample-size indicator

### Recent games
- Date
- Opponent
- Result
- Quarter scores
- Team statistics

### Player intelligence
- Verified player averages
- Recent form
- Role indicators

### Tactical/statistical priorities
- Only recommendations supported by verified evidence
- Explicitly label insufficient evidence

### Sources
- Fixture IDs
- Screenshot count
- Verification timestamps

## Game report

- Fixture header
- Final score
- Quarter-by-quarter scores
- Team box score comparison
- Player box scores
- Statistical differentials
- Evidence/source metadata

## Output requirements

- A4 print layout
- Clear section hierarchy
- Page numbers
- Report generation timestamp
- No fabricated or unverified statistics
